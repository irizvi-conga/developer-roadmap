# Serverless Computing
 
Serverless computing is a model where the cloud provider manages all infrastructure automatically. You deploy code (functions) that run in response to events, with no servers to provision, patch, or scale. The provider handles execution environment management, scales to zero when idle, and charges only for the compute time consumed during function execution. It shifts the operational model from managing capacity to writing event-driven logic.
