# CDN & Edge Caching
 
A CDN (Content Delivery Network) distributes static and cacheable content (images, scripts, video, API responses) to servers located geographically close to end users, reducing latency and offloading traffic from the origin server. Edge caching stores responses at the CDN layer so repeated requests are served without reaching the origin. CloudFront, Cloud CDN, and Azure CDN are the major managed options. CDNs are also used as a first line of defense against DDoS attacks by absorbing traffic at the edge before it reaches origin infrastructure.
