# Hybrid Cloud
 
A hybrid cloud connects private and public cloud environments, allowing workloads to move between them. A common pattern is running sensitive or latency-critical workloads on-premises while using public cloud for burst capacity, backups, or less sensitive services. Hybrid architectures require careful network design and consistent identity and security policies across both environments.
