# Region, Availability Zone

A region is a geographic area where a cloud provider operates one or more data centers, such as us-east-1 or europe-west1. Within a region, availability zones are physically separate data centers connected by low-latency links. Distributing workloads across availability zones protects against single data center failures without the latency of cross-region replication.
