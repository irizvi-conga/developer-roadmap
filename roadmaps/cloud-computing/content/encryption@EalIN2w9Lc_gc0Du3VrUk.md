# Encryption
 
Encryption protects data by transforming it into an unreadable format that can only be decoded with the correct key. Encryption at rest protects stored data (in databases, object storage, disk volumes) from unauthorized access if physical or logical storage is compromised. Encryption in transit protects data moving over networks using TLS, preventing interception. Cloud providers encrypt managed services by default and offer key management services (AWS KMS, Cloud KMS, Azure Key Vault) for managing and rotating encryption keys.
