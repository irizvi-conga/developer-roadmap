# Provisioning
 
Provisioning is the process of setting up and configuring cloud resources so they are ready to use. This includes creating instances, allocating storage, configuring networks, and applying security policies. Provisioning can be done manually through a console, programmatically via an API, or declaratively through Infrastructure as Code tools.
