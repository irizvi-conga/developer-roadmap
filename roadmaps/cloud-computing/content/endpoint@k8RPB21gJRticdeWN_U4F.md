# Endpoint

An endpoint is a URL or network address where a service can be reached. Cloud services expose endpoints for APIs, storage buckets, databases, and load balancers. Endpoints can be public (accessible from the internet) or private (accessible only within a VPC). Managing endpoints is a routine part of configuring cloud services and access control.
