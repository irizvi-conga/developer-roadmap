# File Storage

File storage provides a managed shared filesystem accessible by multiple instances simultaneously over standard protocols like NFS or SMB. Unlike block storage, which is attached to a single instance, file storage can be mounted by many instances at once, making it suited for shared application data, content management systems, and HPC workloads that require a common filesystem. AWS EFS, Google Filestore, and Azure Files are the main managed offerings.
