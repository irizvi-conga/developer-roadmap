# Workload

A workload is any application, service, or process running on cloud infrastructure. The term is used to describe what you are running without specifying how: a web application, a batch job, a machine learning training run, and a real-time data pipeline are all workloads. Cloud architecture decisions are often framed around workload characteristics such as latency sensitivity, statefulness, and compute intensity.
