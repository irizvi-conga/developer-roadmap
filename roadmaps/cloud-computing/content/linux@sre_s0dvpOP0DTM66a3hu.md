# Linux
 
Linux is the operating system that runs the vast majority of cloud servers, containers, and managed services. Working in the cloud means reading logs, navigating filesystems, managing processes, and configuring services from a Linux shell. A solid grasp of Linux is assumed across the entire cloud stack.
