# AWS
 
AWS (Amazon Web Services) is the largest cloud provider by market share, launched by Amazon in 2006. It offers over 200 services across compute, storage, networking, databases, machine learning, and more, available in regions across every major continent. AWS is the default choice for many organizations and has the broadest ecosystem of third-party integrations and community resources.
