# NAT & IP Management
 
Resources in private subnets often need to make outbound requests to the internet (to download updates, call external APIs) without being reachable from outside. A NAT gateway handles this by translating private IP addresses to a public one for outbound traffic. IP management in cloud environments also covers elastic IP allocation (static public IPs), IPv4 vs IPv6 planning, and CIDR block sizing to avoid address space exhaustion as a VPC grows.
