# Data Archiving

Data archiving is the long-term retention of data that is rarely accessed but must be preserved for compliance, legal, or historical purposes. Archive storage classes are designed for this use case, offering very low storage costs in exchange for slow retrieval. Archiving strategies include setting lifecycle rules to move aging data to archive tiers, enabling retention locks to prevent deletion before a defined period, and maintaining audit trails for regulatory compliance.
