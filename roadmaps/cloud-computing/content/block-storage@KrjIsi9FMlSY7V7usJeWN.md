# Block Storage

Block storage provides raw storage volumes that attach to instances and behave like physical disks. The operating system formats them with a filesystem and reads and writes to them at the block level. Block storage offers low latency and high IOPS, making it the right choice for database volumes, operating system disks, and any workload that requires fast random read/write access. AWS EBS, Google Persistent Disk, and Azure Managed Disks are the standard managed block storage options.
