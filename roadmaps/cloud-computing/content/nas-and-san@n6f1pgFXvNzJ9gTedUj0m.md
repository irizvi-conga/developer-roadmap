# NAS and SAN
 
NAS (Network Attached Storage) provides file-level storage access over a network, typically using NFS or SMB protocols. SAN (Storage Area Network) provides block-level storage access over a dedicated high-speed fabric, appearing to the server as a locally attached disk. Both technologies predate cloud computing and remain relevant in private cloud and hybrid architectures. Cloud-managed file storage (EFS, Filestore) and block storage (EBS, Persistent Disk) are the cloud equivalents of NAS and SAN respectively.
