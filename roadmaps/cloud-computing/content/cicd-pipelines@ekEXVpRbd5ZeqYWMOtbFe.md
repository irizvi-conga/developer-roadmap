# CI/CD Pipelines

A CI/CD pipeline is an automated workflow that runs whenever code changes are committed. Continuous Integration (CI) builds and tests the change to verify it does not break existing functionality. Continuous Delivery (CD) packages the artifact and ensures it is always in a deployable state. Continuous Deployment goes one step further and pushes to production automatically when all checks pass. Cloud providers offer managed pipeline services (AWS CodePipeline, Google Cloud Build, Azure DevOps) that integrate with source control, artifact registries, and deployment targets.
