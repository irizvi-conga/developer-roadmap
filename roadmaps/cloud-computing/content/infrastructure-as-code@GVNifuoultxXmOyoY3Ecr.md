# Infrastructure as Code
 
Infrastructure as Code treats cloud resources the same way software treats application logic: defined in files, stored in version control, reviewed through pull requests, and applied through automated tooling. It replaces manual console clicks with reproducible, diffable configuration and is the foundation of consistent multi-environment deployments.
