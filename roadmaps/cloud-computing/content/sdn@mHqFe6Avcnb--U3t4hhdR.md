# SDN

SDN (Software-Defined Networking) separates the network control plane, which decides where traffic goes, from the data plane, which actually forwards packets. In cloud environments, SDN lets providers manage network topology programmatically, enabling VPCs, dynamic routing, network policies, and virtual appliances without touching physical hardware. OpenFlow is an early SDN protocol; most cloud providers implement proprietary SDN stacks tailored to their infrastructure.
