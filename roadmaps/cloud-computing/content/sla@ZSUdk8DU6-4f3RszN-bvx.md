# SLA
 
An SLA (Service Level Agreement) is a contract between a cloud provider and a customer that defines the expected level of service, typically expressed as an uptime percentage. AWS S3, for example, offers a 99.99% availability SLA. SLAs also specify what compensation the provider offers if the target is not met. Understanding SLAs is important when designing for reliability and choosing between services.
