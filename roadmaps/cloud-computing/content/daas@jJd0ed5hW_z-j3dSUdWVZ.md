# DaaS

DaaS (Desktop as a Service) delivers a virtual desktop environment from the cloud to any device with a browser or thin client. The provider hosts and manages the underlying infrastructure, operating system, and desktop software. It is used by organizations that need to provide a consistent, secure desktop experience to remote or distributed workforces without managing physical machines.
