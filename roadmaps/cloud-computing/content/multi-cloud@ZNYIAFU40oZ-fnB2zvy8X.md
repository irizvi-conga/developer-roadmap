# Multi-Cloud
 
Multi-cloud means using services from more than one cloud provider simultaneously. Organizations adopt multi-cloud to avoid vendor lock-in, meet data residency requirements in regions where one provider has no presence, or use best-of-breed services from different providers. It increases operational complexity and requires tooling that works across providers, such as Terraform or Kubernetes.
