# Resource Optimization

Resource optimization reduces cloud spend by eliminating waste and right-sizing infrastructure. Common patterns include terminating unused instances and idle resources, downsizing over-provisioned instances based on actual utilization data, using auto scaling to avoid paying for unused capacity, and replacing always-on instances with serverless or spot workloads where appropriate. Cloud providers offer optimization recommendations (AWS Compute Optimizer, GCP Recommender) that identify specific resources to resize or delete.
