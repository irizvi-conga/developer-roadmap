# Hypervisors
 
A hypervisor is the software layer that makes virtualization possible. It sits between the physical hardware and the virtual machines running on top of it, allocating CPU, memory, and I/O resources to each VM while keeping them isolated from one another. Type 1 hypervisors (KVM, VMware ESXi, Hyper-V) run directly on bare metal and are used by all major cloud providers. Type 2 hypervisors (VirtualBox, VMware Workstation) run on top of a host operating system and are used primarily for local development.
