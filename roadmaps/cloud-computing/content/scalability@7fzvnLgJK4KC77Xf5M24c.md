# Scalability
 
Scalability is the capacity of a system to handle growing demand. Vertical scaling adds more power to a single machine (bigger instance). Horizontal scaling adds more machines. Cloud environments favor horizontal scaling because it avoids single points of failure and can be automated. Scalability is a design property, while elasticity is the mechanism that achieves it dynamically.
