# Multi-Tenancy

Multi-tenancy means multiple customers share the same physical infrastructure, with each customer's data and workloads isolated from the others. Cloud providers are multi-tenant by default. Isolation is enforced through virtualization, network policies, and IAM controls. Understanding multi-tenancy is important for reasoning about security boundaries and compliance requirements.
