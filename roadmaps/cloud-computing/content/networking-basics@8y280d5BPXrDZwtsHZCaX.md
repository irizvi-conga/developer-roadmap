# Networking Basics
 
Networking basics covers the fundamental concepts that underpin how computers communicate: IP addresses, subnets, ports, protocols (TCP, UDP, HTTP, HTTPS), and DNS. Cloud networking builds directly on these concepts, and without them, topics like VPCs, security groups, and load balancers are difficult to reason about. Understanding what happens when a request travels from a client to a server is the minimum baseline.
