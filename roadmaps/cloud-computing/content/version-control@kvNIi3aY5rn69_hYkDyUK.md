# Version Control
 
Version control tracks changes to code and configuration over time, enabling collaboration and rollback. Git is the standard tool. In cloud workflows, version control is the foundation of CI/CD pipelines, Infrastructure as Code practices, and GitOps, where the Git repository is the single source of truth for both application and infrastructure state.
