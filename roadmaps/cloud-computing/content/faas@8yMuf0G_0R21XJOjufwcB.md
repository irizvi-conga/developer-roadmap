# FaaS

FaaS (Function as a Service) lets you deploy individual functions that run in response to events, with no server management. The provider handles all infrastructure, scaling to zero when idle and scaling out automatically under load. AWS Lambda, Google Cloud Functions, and Azure Functions are the main platforms. FaaS is the compute model behind serverless architectures.
