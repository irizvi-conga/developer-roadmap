# Codex

Codex is OpenAI's AI coding agent. It can write features, fix bugs, explain unfamiliar codebases, and propose pull requests, running in the terminal, in IDEs, or in the cloud. For FDEs, it is a practical way to move quickly inside customer repositories, and it is a tool customer engineering teams may already be using.
