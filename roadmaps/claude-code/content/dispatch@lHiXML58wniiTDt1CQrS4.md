# Dispatch

Dispatch is a persistent conversation with Claude in Cowork that you message from your phone. You describe a task, and Dispatch decides how to handle it. When the task is development work, it starts a Claude Code session in the Desktop app, such as fixing a bug, updating dependencies, running tests or opening a pull request. Those sessions appear in the Code tab sidebar, and you get a phone notification when one finishes or needs approval. Dispatch requires a Pro or Max plan and your computer must stay on with the Desktop app running.
