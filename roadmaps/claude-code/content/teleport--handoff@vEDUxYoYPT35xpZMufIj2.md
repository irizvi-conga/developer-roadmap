# Teleport and Handoff

Teleport and handoff move work between surfaces. `claude --teleport` pulls a cloud session into your terminal, checking out its branch and loading the conversation, and `/teleport` (or `/tp`) does the same from inside a session. `claude --cloud "task"` starts a new cloud session from your terminal, and `/desktop` continues the current terminal session in the Desktop app. The terminal copy of a teleported session is separate, so new work there does not appear in the cloud session.
