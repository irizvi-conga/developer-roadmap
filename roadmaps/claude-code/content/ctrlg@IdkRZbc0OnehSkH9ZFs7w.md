# Ctrl+G

Ctrl+G opens your current prompt in your default text editor, so you can write or edit a long prompt in a full editor instead of the input line. `Ctrl+X Ctrl+E` does the same and is the readline-native binding. It also works when you are writing a custom response to a question from Claude. A setting in `/config` can add Claude's previous reply as commented context in the editor.
