# Slack / Claude Tag

Slack integrations let you hand coding tasks to Claude from a team conversation. Mentioning `@Claude` in a channel with a bug report or request starts a Claude Code cloud session, posts progress in the thread, and returns a summary with buttons to view the session or create a pull request. Claude Tag is the organization-managed version for Team and Enterprise plans, where @Claude runs under a shared identity with admin-configured access. The earlier per-user Claude Code in Slack only works for Pro and Max accounts in workspaces not connected to Claude Tag, and it only works in channels, not direct messages.
