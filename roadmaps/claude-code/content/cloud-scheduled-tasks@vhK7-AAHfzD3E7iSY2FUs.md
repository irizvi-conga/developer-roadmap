# Cloud Scheduled Tasks

Cloud scheduled tasks, formerly called routines, are saved Claude Code configurations that run on Anthropic-managed cloud infrastructure, so they work when your laptop is closed. A task holds a prompt, one or more repositories and a set of connectors. It can start from a schedule, from an HTTP call to its own API endpoint, or from GitHub events such as a pull request or release. You create them on the web, in the Desktop app, or with `/schedule` in the CLI, and each run is a full cloud session you can open and review.
