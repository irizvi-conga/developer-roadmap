# Channels

Channels are MCP server plugins that push messages, alerts and webhooks into a Claude Code session that is already running. They support platforms like Telegram, Discord and iMessage, so Claude can react to events while you are away from the terminal. You install a channel as a plugin, set up its credentials and pair your account. Because events arrive in your open session instead of starting a new one, channels fit always-on setups.
