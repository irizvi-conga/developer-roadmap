# Agent View

Agent view is a single screen for managing many Claude Code sessions at once. You open it with `claude agents`, and it shows what each session is doing and which ones need your input. Background sessions are full conversations that keep running without a terminal attached, so you can close the screen or your shell and they continue. From the list you can dispatch a new session by typing a prompt, peek at a session's latest output and reply, attach for the full conversation, or stop, rename and pin sessions.

Visit the following resources to learn more:
