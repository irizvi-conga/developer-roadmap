# Mobile

Claude Code does not have a separate mobile app. The Claude app for iOS and Android is a client that reaches Claude Code sessions in the Code tab. From your phone you can start and follow cloud sessions, drive a session running on your own computer through Remote Control, or message Dispatch a task. The `/mobile` command shows a QR code that opens the right app store for your phone.
