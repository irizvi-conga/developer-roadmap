# Code Review

Claude Code has three built-in ways to review code, and they differ in where they run and how deep they go. `/code-review` runs in your session and gives quick feedback on your own diff. Ultrareview runs a larger fleet of agents in a cloud sandbox before you merge. Code Review on pull requests runs automatically on GitHub for Team and Enterprise organizations. You can also run Claude in your own CI, or write a reviewer as a subagent or skill.

Visit the following resources to learn more:

- [@official@Code Review](https://code.claude.com/docs/en/code-review)
- [@official@Compare ways to get a review](https://code.claude.com/docs/en/code-review#compare-ways-to-get-a-review)
