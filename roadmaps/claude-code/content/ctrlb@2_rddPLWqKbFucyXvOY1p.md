# Ctrl+B

Ctrl+B moves running Bash commands and agents to the background. The session stays free for your next prompt while the work continues, which helps with long builds, dev servers or test runs. Tmux users press the shortcut twice, because tmux uses Ctrl+B as its own prefix.
