# /agents

The `/agents` command points you to subagent management. On current versions it prints a reminder to ask Claude to create or manage subagents, or to edit the files in `.claude/agents/` or `~/.claude/agents/` yourself. On v2.1.197 and earlier it opened an interactive interface for creating and editing subagents. Subagents run in their own context window with their own system prompt and tools, which keeps specialized work like security audits or test writing out of the main conversation.
