# /code-review

`/code-review` is a bundled skill that reviews your current diff, a pull request, a branch or a path for bugs. It runs in your own session on any plan, and an optional level from `low` to `max` sets how thorough the review is. The `--comment` flag posts findings as inline comments on a pull request, `--fix` applies them to your working tree, and `--max-findings` limits how many are reported. Pass a PR number to review a teammate's change before approving it.
