# Ctrl+O

Ctrl+O toggles the transcript viewer, a detailed view of everything that happened in the session. It shows tool usage and execution, with a timestamp and the model used on each assistant message. It also expands lines that collapse by default, such as MCP calls that appear as a single "Called slack 3 times" line. Use it when you want to see what Claude actually did behind a short summary.
