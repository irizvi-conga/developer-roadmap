# Chrome

The Chrome integration connects Claude Code to your browser through the Claude in Chrome extension. Claude can open tabs, click, type, read console errors and the page structure, so it can test a web app, debug a failing page or fill in forms without leaving your session. It shares your browser's login state, and pauses when it hits a login page or CAPTCHA so you can handle it. You start it with `claude --chrome` or turn it on for every session with `/chrome`.
