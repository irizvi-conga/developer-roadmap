# Desktop Scheduled Tasks

Desktop scheduled tasks run recurring Claude Code work on your own machine through the Desktop app. They do not need an open session, but the computer has to be on. Because they run locally, they can use your local files, tools and MCP configuration, and permission prompts can be set per task. Use them when a scheduled job needs access to files that a cloud task cannot reach.
